# cubosapiens_html_formatter

A browser-based HTML Formatter utility built for the CuboSapiens ecosystem.

## Features

- Format / Beautify HTML
- Minify HTML
- Copy formatted output
- Dark mode & Light mode
- Responsive design
- Keyboard accessible
- Persistent theme preference (localStorage)

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome icons

## Running Locally

1. Open the project folder
2. Right-click `index.html`
3. Click **Open with Live Server**

## Route

`/tools/html-formatter`
